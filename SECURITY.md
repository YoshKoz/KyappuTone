# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in KyappuTone, please **do not open a public GitHub issue**. Public disclosure before a fix is available could put other users at risk.

Report it privately through GitHub's security advisory flow for this repository:

<https://github.com/YoshKoz/KyappuTone/security/advisories/new>

If private advisories are unavailable, contact the repository owner through GitHub without including exploit details in a public thread.

Please include:
- A description of the vulnerability
- Steps to reproduce it
- The potential impact, if known
- Your Windows version and where you installed KyappuTone from

Reports will be acknowledged as soon as possible and kept confidential while the issue is investigated and resolved. Once a fix is released, you will be credited in the release notes if you would like.

## Scope

This policy covers the KyappuTone application itself. Third-party libraries used by the project are out of scope — please report those vulnerabilities directly to their respective maintainers.
