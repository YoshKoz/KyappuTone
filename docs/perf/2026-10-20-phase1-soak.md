# Phase 1 audio soak — 2026-10-20

## Method

- Harness: `tools/KyappuTone.Soak` (Release), driven by `scripts/soak-audio.ps1`.
- Source material: three generated 60 s stereo WAVs (220/330/440 Hz fundamentals), gaplessly crossfaded with a 2 s overlap.
- Signal path: FFmpeg decode → mix → crossfade → ten-band EQ (Rock preset, −3 dB preamp) → limiter → WASAPI shared-mode output (10 ms).
- Phases: 7.5 minutes EQ only, then 7.5 minutes EQ plus a simulated 60 Hz visualizer mapping loop (64 log-spaced bars).
- Sampling: every 30 s, CPU as percent of one core (`TotalProcessorTime` delta / wall delta), working set, managed heap, rendered audio seconds, render callbacks, unexpected device stops.
- Pass criteria: no unexpected device stops, render callbacks > 0, rendered-audio / wall-clock ratio ≥ 0.5.

Limitation: this measures the audio engine and DSP chain, not the packaged UI. The 1 h packaged-app run with the tray, SMTC, taskbar overlay, and the on-screen visualizer remains a manual pre-release check.
