# KyappuTone branding

The KyappuTone identity is an original design: a rounded "K" whose two arms are
sound-wave strokes in amber and teal, set on a deep teal-navy tile.

Source files (SVG):

- `kyapputone-icon.svg` — square app icon with wordmark (`Assets/AppIcon.png`, `.ico`)
- `kyapputone-tile.svg` — mark-only square tile (Store tiles)
- `kyapputone-mark-light.svg` — light mark for dark surfaces (`Assets/Store/Logo_Dark.png`)
- `kyapputone-mark-dark.svg` — dark mark for light surfaces (`Assets/Store/Logo_Light.png`)
- `kyapputone-splash-dark.svg` / `kyapputone-splash-light.svg` — in-app splash lockups
- `kyapputone-wide.svg` — horizontal lockup (wide tile)

The PNG/ICO files under `Assets/` and `Assets/Store/` are generated from these
sources with ImageMagick. Keep the SVG sources as the editable originals.
